# 🏓 Pong – Classic Arcade Game

**Pong** is a simple recreation of the classic arcade table tennis game, where two paddles hit a ball back and forth. The objective is to outscore your opponent by making the ball pass their paddle.

This project focuses on core game development concepts like collision detection, movement, and real-time gameplay mechanics.

---

## 🎮 Gameplay

Control paddles and keep the ball in play as long as possible. The game tests your reflexes and timing as the ball speeds up and angles change.

---

## 🎮 Controls

* **W key** → Move Left Paddle Up
* **S key** → Move Left Paddle Down
* **Up Arrow (↑)** → Move Right Paddle Up
* **Down Arrow (↓)** → Move Right Paddle Down

---

## 🧠 Features

* Classic Pong gameplay
* Two-player local mode
* Smooth paddle and ball movement
* Collision detection and scoring system
* Lightweight and easy to run

## ▶️ How to Run the Game

⚠️ **Important:** Do NOT open `index.html` directly (double-click).
The game must be run using a **local server**.

### Steps:

1. **Clone the repository**

   ```bash
   git clone https://github.com/Aniketpatra007/Pong.git
   ```

2. **Open the project folder**

   ```bash
   cd Pong
   ```

3. **Run using Live Server (Recommended)**

   * Open the project in VS Code
   * Install the **Live Server** extension (if not already installed)
   * Right-click on `index.html`
   * Click **"Open with Live Server"**

4. Your browser will open automatically and the game will start 🎉
